# PLC Benchmark Datasets

Dataset-only distribution of Agents4PLC and Spec2Control tasks. Evaluation,
code-generation, data-conversion and runtime scripts are not included.

| Dataset | Tasks | Contents |
| --- | ---: | --- |
| [Agents4PLC](agents4plc-benchmark/README.md) | 117 per version | Original tasks and revised requirements/properties |
| [Spec2Control](spec2control-benchmark/README.md) | 65 sections | Task specifications, reference ST projects, static oracle data and subset lists |

Reference answers and oracle data must be kept separate from solver inputs when
conducting blind evaluation. See each dataset's README for layout and provenance.
Third-party datasets retain their licenses; see [notices](THIRD_PARTY.md).
