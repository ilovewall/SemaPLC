# ST Reference Projects

Project-derived Structured Text counterparts of `../fbd-baseline/<plant>/`.
Each plant has OpenPLC project metadata, program POUs and shared function blocks.
The source material is the reviewed FBD baseline and its `2_control_logic.txt`.

These files are reference data, not solver inputs. Conversion tools and evaluation
scripts are not included. Preserve program and function-block interfaces when
using the references. Coverage gaps are documented in
[BASELINE_GAPS.md](BASELINE_GAPS.md).
